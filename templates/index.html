Make your remaining tokens last
  • ⚡
    Use /compact mid-session
    When a session grows long, type /compact in the Claude Code prompt. It summarises the history and resets context — often cutting subsequent call sizes by 50–70%.
  • 🎯
    One task per session
    Each new Claude Code invocation starts with a fresh context. Avoid doing 10 unrelated things in one session — the accumulated history inflates every subsequent call.
  • ✂️
    Truncate tool outputs
    Pipe Bash results through | head -50 or | grep pattern. Every byte a tool returns gets re-sent on every future call in the same session.
  • 📄
    Read files with line ranges
    Instead of reading an entire file, ask Claude to read specific sections: "read lines 20–80 of config.py". The Read tool supports offset/limit to avoid pulling in irrelevant content.
  • 🧠
    CLAUDE.md = free cache
    Your CLAUDE.md files are cached across all calls in a session. At 99.9% cache hit rate, yours is already excellent — keep it up. This is what makes Pro/Max plans stretch so far.
  • 💬
    Be precise in prompts
    Vague prompts lead to back-and-forth. A precise prompt with context ("Fix the TypeError on line 42 of api/server.py — it's failing because X") costs fewer total tokens than 3 rounds of clarification.
